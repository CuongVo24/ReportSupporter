## 1. Purpose

Import là **lớp tiếp nhận** (ingestion layer): biến tài liệu có sẵn của người dùng — **DOCX, PDF, XLSX, PPTX** và Markdown — thành nội dung Markdown trong workspace để **viết tiếp, check, và xuất lại**.

Định vị sản phẩm (giữ nguyên identity `ProductPRD.md`): ReportSupporter **không** trở thành trang converter dùng-một-lần. Import là **import-to-edit** — giá trị nằm ở chuỗi phía sau (Format/Check/Export/Present), file convert chỉ là cửa vào. Kết hợp với Export hiện có (PDF/DOCX/PPTX), app thành **round-trip**: nhận file thầy/cô hoặc bản cũ → chỉnh trong workspace → xuất bản chuẩn.

Triết lý không đổi: **Markdown-first, client-side-first**. Mọi converter chạy trong trình duyệt (không upload, không backend, giữ privacy posture), và output luôn là Markdown thuần — nội dung import đi qua đúng pipeline `remark-parse` như nội dung gõ tay.

## 2. Scope

### In scope (Phase 5 — W21-W24)

- Converter registry: route file theo extension + MIME, mỗi format một converter đăng ký (`ImportConverter`).
- Universal dropzone: một điểm nhận mọi format (nâng cấp `MarkdownImportDropzone`; đường `.md` hiện có = converter đầu tiên).
- **DOCX** (W21): `mammoth` → HTML → sanitize → `rehype-remark` → Markdown GFM; ảnh nhúng → `ReportAsset`.
- **PDF** (W22): `pdfjs-dist` trích text + font/position; heuristic font-size → heading, merge → paragraph, list detection; trích ảnh; phát hiện trang scan.
- **XLSX** (W23): SheetJS — mỗi sheet → section chứa bảng GFM; merged cells/number format/row cap.
- **PPTX** (W23): `jszip` (dep sẵn có) + parse slide XML — title → heading, body → bullets, notes → blockquote, media → `ReportAsset`.
- Warnings chuẩn hoá (`ImportWarningCode`) — converter không im lặng nuốt nội dung.
- Import preview diff (W24): duyệt kết quả, remap heading, chọn append/replace trước khi commit.
- Check-on-import (W24): Check engine chạy trên `ImportDraft`, issues `module: "import"`.
- OCR **experimental** (W24): `tesseract.js` lazy-load, flag default OFF, chỉ chạy sau explicit user action.

### Out of scope

- ❌ Backend/server conversion (Docling/Marker/markitdown server là hardening tùy chọn tương lai — ngoài Phase 5).
- ❌ Hứa "mọi định dạng" — chỉ 4 format curated + `.md`; format khác từ chối có thông báo rõ.
- ❌ Fidelity 1:1 layout gốc — mục tiêu là **cấu trúc đúng** (heading/list/table/image), không phải bản sao trang.
- ❌ OCR mặc định / OCR chất lượng production — W24 chỉ experimental, tắt mặc định.
- ❌ Import formula Excel (chỉ lấy **giá trị** cell, không engine công thức), animation/SmartArt/chart PPTX (→ `unsupported-element`).
- ❌ Đổi scope Write: Write vẫn chỉ ăn Markdown + assets; Import bàn giao qua `ImportDraft`.

## 3. Data Model

### 3.1 Canonical types (định nghĩa tại CanonicalTypes §11 — Import chỉ tiêu thụ)

- `ImportSourceFormat` — `"markdown" | "docx" | "pdf" | "xlsx" | "pptx"`.
- `ImportWarningCode` / `ImportWarning` — mã cảnh báo chuẩn, có `location` ("page 3", "sheet Data", "slide 5").
- `ImportResult` — output thuần của converter: `markdown + assets + warnings`.
- `ImportConverter` — đơn vị đăng ký registry: `format`, `extensions`, `mimeTypes`, `maxBytes`, `convert(file)`.
- `ImportDraft` — draft trình user duyệt: `result + sections đề xuất + mode append/replace + issues?`.

> `MarkdownImportDraft` (type cục bộ tại `src/modules/write/markdown-import.ts`) được reconcile/absorb vào `ImportDraft` ở W21 — không tồn tại hai shape draft song song.

### 3.2 Warning policy

Converter **bắt buộc** phát warning khi mất nội dung — người dùng phải biết cái gì không sang được:

| Code | Khi nào | Converter |
|---|---|---|
| `unsupported-element` | SmartArt/chart/OLE/textbox lạ bị bỏ | docx, pptx |
| `scanned-page` | Trang PDF không có text layer | pdf |
| `table-flattened` | Bảng không tái tạo được → text | pdf, docx |
| `sheet-truncated` | Sheet vượt row cap (500) | xlsx |
| `image-skipped` | Ảnh hỏng/quá lớn/không decode được | tất cả |
| `heading-guessed` | Heading suy từ heuristic, cần xác nhận | pdf, ocr |
| `file-too-large` | Vượt `maxBytes` (mặc định 50MB) | registry |

## 4. Architecture — Converter Registry

```
File (drop/paste/picker)
   │
   ▼
UniversalImportDropzone ──▶ registry.resolve(file)   // extension + MIME; không match → reject có thông báo
   │                              │
   │                              ▼
   │                       ImportConverter.convert(file)      // chạy trong import worker (W24)
   │                              │
   │                              ▼
   │                       ImportResult { markdown, assets, warnings }
   ▼                              │
ImportPreviewDialog ◀─────────────┘
   │   • render Markdown kết quả (pipeline chuẩn)
   │   • remap heading level / chọn append|replace
   │   • Check engine chạy trên draft → issues (module: "import")
   ▼
commit → appendSections/replaceSections + import-assets   // đường Write hiện có, không đổi
```

Nguyên tắc:

1. **Registry là điểm mở rộng duy nhất.** Thêm format = thêm một `ImportConverter`, không sửa dropzone/preview.
2. **Markdown là giao diện duy nhất** (`PipelineContract.md` §4) — converter không sinh mdast; reverse pipeline (`rehype-remark`) chỉ sống trong `src/modules/import/`.
3. **Commit qua đường Write hiện có** — `appendSections`/`replaceSections` + `import-assets`; Import không tự ghi IndexedDB.
4. **Fail một file không giết batch** — mỗi file một kết quả/lỗi độc lập.

## 5. Per-format Strategy & Limitations

| Format | Engine | Chiến lược | Giới hạn đã chấp nhận |
|---|---|---|---|
| DOCX | `mammoth` | docx → HTML semantic → sanitize → `rehype-remark` → MD GFM; ảnh base64 → `ReportAsset` | Style/màu/box mất (chủ đích — Format lo layout); track-changes lấy bản accepted |
| PDF | `pdfjs-dist` | Text + font/position per page → cluster font-size → heading map; merge line → paragraph; bullet/number regex → list | Bảng phức tạp → flatten + warning; 2 cột có thể lệch thứ tự; trang scan → `scanned-page` |
| XLSX | SheetJS `xlsx` | Mỗi sheet → `## <Sheet>` + bảng GFM; giá trị đã format (không formula engine) | Merged cells flatten; row cap 500; chart bỏ qua |
| PPTX | `jszip` + XML parse | `ppt/slides/slideN.xml`: title → `##`, body → bullets theo indent; notes → blockquote; `ppt/media/*` → `ReportAsset` | SmartArt/chart/animation → `unsupported-element`; vị trí tự do trên slide → thứ tự đọc XML |
| Scan/OCR | `tesseract.js` (W24, experimental) | Lazy-load WASM, explicit action, vie+eng; text → paragraph + `heading-guessed` | Flag OFF mặc định; chất lượng không cam kết; chậm — có progress + cancel |

## 6. Performance & Worker

- Converter nặng chạy trong **import worker** riêng (W24) — main thread không block >200ms; `pdfjs-dist` dùng worker riêng của nó (bundle local, **không CDN** — posture offline).
- Progress reporting per file (parse/convert/assets) qua `postMessage`.
- `maxBytes` 50MB/file (kế thừa `MAX_MARKDOWN_IMPORT_BYTES`); PDF page cap 300; XLSX row cap 500/sheet.
- OCR/tesseract **lazy dynamic import** — không vào bundle chính; chỉ tải khi user bấm.
- Memory: revoke object URL sau đọc; asset > giới hạn → `image-skipped` thay vì OOM.

## 7. Interaction với module khác

- **Write (1):** nhận `ImportDraft` → commit qua `appendSections`/`replaceSections`; dropzone/preview thuộc surface Write nhưng logic sống ở `src/modules/import/` (import qua `index.ts`).
- **Format (2):** không đổi — heading import KHÔNG mang số chương hard-code; converter phải strip số kiểu "1.2 " đầu heading (Check rule `hardcoded-heading-number` là lưới an toàn).
- **Check (3):** chạy trên `ImportDraft` trước commit (W24); issues `module: "import"`.
- **Export (4):** không đổi — round-trip đi qua pipeline chuẩn.

## 8. Risks

| Risk | Level | Mitigation |
|---|---|---|
| PDF heuristic sai heading → cấu trúc rác | High | `heading-guessed` warning + preview diff remap trước commit; fixtures đa nguồn (Word/LaTeX). |
| Kéo dep nặng vào bundle chính | High | Lazy/dynamic import từng converter; tesseract chỉ tải on-demand; kiểm bundle size gate. |
| XSS qua HTML trung gian (mammoth) | High | Sanitize bắt buộc trước `rehype-remark` (PipelineContract §4). |
| Mất nội dung im lặng | Medium | Warning policy §3.2 bắt buộc; QA đối chiếu nguồn↔kết quả trên fixtures. |
| SheetJS npm registry cũ | Medium | Cài từ dist chính thức (cdn.sheetjs.com tarball), pin version — ghi ở install matrix W23. |
| Scope leo thang "convert mọi thứ" | Medium | Out-of-scope §2 khoá; format lạ reject có thông báo. |
